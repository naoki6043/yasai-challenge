秋冬やさいチャレンジ v6（学年別・任意クイズ版）

主な仕様
- 初回起動時に1〜6年生から学年を選択。低・中・高学年で教材と問題を切替。
- HOMEは野菜10種類、各野菜3料理を横並び表示。レシピNo.は表示しない。
- 各料理の「作った」「食べた」は、レシピ詳細で記録したイベントからHOMEに自動反映。
- 「作った」「食べた」は別々に記録。同一料理の別日の記録もイベントとして保持。
- 学習は喫食回数に応じて段階的に解放。
- 学習直後にクイズへ誘導しない。2・4・6個の「まなぶ」完了時に、任意の「クイズをえらぶ」コマンドを表示。
- クイズを実施しなくても学習・料理行動を継続可能。
- クイズは完了済み教材の内容だけから出題。
- ローカルイベントとして quiz_choice_open / learning_quiz_start / answer / complete / abandon を保存。
- 記録画面でクイズ提示機会、開始回数、完了回数、開始率、完了率、回答数、正答率を確認可能。

研究用試作の注意
- localStorage保存のみ。サーバー送信・研究者用管理画面・CSV出力・認証は未実装。
- 写真、材料、分量、作り方は正式データ差替え前のプレースホルダー。
- 正式研究利用前に、教材・設問の内容妥当性、同意・匿名ID・データ管理・版固定等の確認が必要。
