秋冬やさいチャレンジ v9：Googleスプレッドシート連携版

1. 共同編集・公開管理マスター.xlsx をGoogle Driveへアップロードし、Googleスプレッドシートとして開く。
2. 拡張機能 > Apps Script を開き、GoogleAppsScript_公開レシピAPI.gs を貼り付ける。
3. デプロイ > 新しいデプロイ > ウェブアプリ。
4. 発行されたURLを config.js の RECIPE_API_URL に貼る。
5. 学生は入力後「確認待ち」、教員確認後に「公開」。
6. アプリは起動/再読み込み時に「公開」の行だけ取得する。

重要：児童の研究データはこの共同編集スプレッドシートに保存しない。
